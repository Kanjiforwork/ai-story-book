# Public-domain sample books

The bundled UTF-8 source texts come from Project Gutenberg. The application
removes the Gutenberg header and footer before creating a project, while these
files retain the original source notice.

- `a-christmas-carol.txt`: Charles Dickens, _A Christmas Carol_, Project
  Gutenberg eBook #46 — https://www.gutenberg.org/ebooks/46
- `jekyll-and-hyde.txt`: Robert Louis Stevenson, _The Strange Case of Dr Jekyll
  and Mr Hyde_, Project Gutenberg eBook #43 —
  https://www.gutenberg.org/ebooks/43

Both source pages identify their texts as public domain in the USA. Reviewers
should check local law before redistributing the files outside this local
assessment repository.
